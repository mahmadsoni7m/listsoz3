# ListSoz

Барномаи Android (Kotlin + Jetpack Compose + Material 3) барои донишҷӯён: реферат/КМД, ҳуҷҷати матнӣ, PDF, DOCX, дастнависи кабуд ва чоп.
Package: `tj.soni.listoffice` • minSdk 26 • targetSdk 34.

## ВАЗЪИ ВОҚЕӢ (ҳалим)
**Ин лоиҳа дар муҳити сохтан компилятсия НАШУДААСТ** (Gradle, Kotlin ва шабакаи интернет дар он ҷо набуд). Код хаттӣ тафтиш шуд (баландии қавсҳо, YAML, XML), аммо аввалин build дар GitHub Actions метавонад хатоҳои хурд нишон диҳад. Хатои build-ро пинҳон намекунем: онро аз Actions → build-reports гиред.

### Тайёр аст (бо кор дар код)
- **Presentation Studio**: илова/нусха/нест/ҷобаҷогузории слайдҳо, 6 қолаби ранг, 5 тарҳбандӣ (сарлавҳа, матн, сурат рост/чап, сурат пурра), сурат аз галерея (худкор хурд ва рост мешавад), ихтисори худкори андозаи матн, рақами слайд, ёддошти баромадкунанда, вақти тахминии баромад, намоиши экрани пурра, нақшаи худкор аз ҳуҷҷат, экспорт ба PPTX (бо сурат) ва PDF
- **Чопи A4 барои слайдҳо**: 1, 2, 4 ё 6 слайд дар як саҳифа, ё 3 слайд + ёддошт бо хатҳо; PDF-и 16:9 барои экран
- Дизайни нав: сарлавҳаи градиентӣ, тайлҳои модулҳо, омори аниматсионӣ, ҳолатҳои холӣ, гузариши мулоим байни табҳо, экрани Танзимот
- Танзимот ва лоиҳаи слайдҳо ҳангоми пӯшидани барнома нигоҳ дошта мешаванд
- Ранги ручка: кабуд, кабуди торик, сиёҳ, бунафш
- Дашборд (омор, ҳуҷҷатҳои охирин, амалҳои зуд)
- Таҳрири матн, автонигоҳдорӣ, ҷустуҷӯ, шумориши калимаҳо, андозаи ҳарф (12/14/16 pt) барои экспорт
- Шаблонҳо: Реферат, КМД, Иншо, Мақола, Ҳисобот, Кори курсӣ, Лоиҳаи таълимӣ — бо забонҳои тоҷикӣ/русӣ/English, бо саҳифаи аввал, нақша, муқаддима, қисми асосӣ, хулоса, адабиёт
- Экспорт: TXT, PDF (A4, рақами саҳифа), DOCX (OOXML-и воқеӣ, рақами саҳифа, сарлавҳаҳо дар марказ), PPTX (16:9)
- Handwriting Studio (ҳошияҳои чап/рост/боло/поён бо мм, сатри сурх, сарлавҳа дар марказ, рақами саҳифа): ручкаи кабуд, 4 услуб, қоғази сафед/хатдор/katak, хати ҳошия, каҷии ҳарфҳо, хати ғайриякхела, PDF-и A4-и бисёрсаҳифа; ҳарфҳои Ғ Қ Ҳ Ҷ Ӯ Ӣ бо нишонаи дастнавис
- Чоп тавассути Android Print Framework (диалоги системавӣ: принтер, нусха, ранг, ориентатсия)
- Файлҳо: кушодан, PDF viewer, тағйири ном, нест кардан, мубодила, содирот/ворид (SAF), ҷустуҷӯ
- Хулосаи офлайн (экстрактивӣ, бе сервер)

### НАТАМОМ / ИМКОН НЕСТ (ҳамчун тайёр нишон дода нашудааст)
- Слайдҳо: диаграмма, ҷадвал, аниматсия ва гузаришҳо дастгирӣ намешаванд; ёддошти баромадкунанда танҳо дар PDF/чопи A4 ҷой дорад (на дар PPTX).
- Room ва DataStore истифода нашудаанд (ҳуҷҷатҳо ҳамчун файл нигоҳ дошта мешаванд).
- Bold/Italic/Underline, ҳамсӯгардонӣ, ҳошияҳо — ҳуҷҷат матни оддӣ аст (rich text нест).
- Шрифтҳои дастнавис (Bad Script, Marck Script, Neucha — иҷозатномаи OFL; Bad Script ва Marck Script ба хати мактабии кириллӣ наздиканд) дар вақти build дар GitHub Actions аз google/fonts зеркашӣ мешаванд. Агар зеркашӣ нашавад, дар лог огоҳӣ (warning) пайдо мешавад ва барнома хати оддии системавиро истифода мебарад. Ҳарфҳои Ғ Қ Ҳ Ҷ Ӣ Ӯ аз ҳарфи асосӣ + нишона сохта мешаванд. Шрифтҳои худатонро низ метавонед ба `app/src/main/assets/fonts/` гузоред (`natural.ttf`, `beautiful.ttf`, `clean.ttf`).
- Диапазони саҳифаҳо ҳангоми чоп: PDF пурра фиристода мешавад; интихоби диапазон метавонад эътибор наёбад.
- DOCX/PPTX-ро мустақиман чоп кардан мумкин нест (аввал PDF созед).
- LLM-и офлайн: дохил нашудааст; «Хулоса» алгоритми оддии такрори калимаҳост, на AI.
- Принтерҳои Bluetooth/Wi-Fi-ро худи Android кашф мекунад; барнома рӯйхати худро надорад.
- Шаблонҳо сохтор месозанд, матни пурраи рефератро не — матнро худи шумо менависед.

## Логотип
Файлҳои логотип дар папкаи `branding/` (SVG, PNG 1024, Play Store 512, wordmark равшан/торик). Нишони барнома дар `app/src/main/res/drawable/ic_bg.xml`, `ic_fg.xml`, `ic_fg_mono.xml` (дастгирии нишони монохромии Android 13+).
